# EISep RNN: Learnable Excitatory-Inhibitory Separation

This repository contains the public experiment code for the paper introducing **EISep RNN**, a recurrent neural network architecture that implements Dale's principle through a learnable excitatory-inhibitory separation.

The experiments evaluate EISep against vanilla RNNs and Dale-constrained baselines across cognitive multi-task learning, continual learning, reinforcement learning, and conventional supervised sequence benchmarks.


## Repository Structure

```text
docs/examples_pub/
├── README.md
├── requirements_neurogym.txt            # Lightweight pip requirements for NeuroGym workflows
├── requirements_mixer.txt               # Lightweight pip requirements for mixer/RL workflows

├── rl/                                  # RL analysis utilities
├── conventional_supervised_learning/    # Scripted sequence benchmark entry points
├── output/                              # Empty/generated-at-runtime figure directory
├── multi-task_learning*.ipynb           # Yang19 multi-task cognitive-task experiments
├── continual_learning*.ipynb            # Continual-learning experiments and ablations
├── reinforcement_learning*.ipynb        # RL training and ablation notebooks
├── reinforcement_learning_analysis*.ipynb
├── initialization_analysis.ipynb
└── modular_perceptual_decision_making.ipynb
```

Run scripts and notebooks from `docs/examples_pub` so relative imports such as `net.*` and `rl.*` resolve correctly.

Generated checkpoints, result files, and figures are not included in the current repository snapshot. Running the notebooks or scripts may create directories such as `result/`, `rl/result/`, `results/`, `models/`, and `output/`.

## Environments

This codebase uses two separate Python environments.

### NeuroGym Environment

Use this environment for:

- multi-task Yang19 cognitive-task experiments
- continual-learning experiments
- initialization analysis
- modular perceptual decision-making analysis
- conventional supervised sequence benchmarks

These notebooks use the `neurogym` kernel. The lightweight requirements file is `requirements_neurogym.txt`.

Create it with:

```bash
cd docs/examples_pub
python -m venv .venv-neurogym
source .venv-neurogym/bin/activate
pip install -r requirements_neurogym.txt
```

The pip requirements are a compact dependency list inferred from the code and the original working environment.

### Mixer Reinforcement-Learning Environment

Use this environment for reinforcement-learning training and most RL analyses:

- `reinforcement_learning.ipynb`
- `reinforcement_learning_halfcheetah.ipynb`
- `reinforcement_learning_multihidden.ipynb`
- `reinforcement_learning_multil1.ipynb`
- `reinforcement_learning_reinit.ipynb`
- `reinforcement_learning_truncate.ipynb`
- `reinforcement_learning_analysis_hmm.ipynb`
- `reinforcement_learning_analysis_performance_table.ipynb`

These notebooks use the `mixer` kernel. The lightweight requirements file is `requirements_mixer.txt`; it reflects the original RL environment, which used Python 3.8, PyTorch 1.12.0, CUDA 11.6, Gym/Gymnasium RL dependencies, Box2D, and MuJoCo packages.

Create it with:

```bash
cd docs/examples_pub
python -m venv .venv-mixer
source .venv-mixer/bin/activate
pip install -r requirements_mixer.txt
```

RL dependencies are version-sensitive, especially Box2D, MuJoCo, CUDA, and older PyTorch packages.


## Datasets and Environments

Most datasets are generated by the code:

- Yang19 cognitive tasks are generated with NeuroGym via `get_collection('yang19')`.
- Continual-learning tasks use NeuroGym task IDs `go`, `anti`, `dlygo`, and `dlyanti`.
- The adding problem and sorting problem are generated synthetically inside their benchmark scripts.
- Sequential MNIST is downloaded automatically by `torchvision.datasets.MNIST('.', download=True, ...)`.
- RL data are generated by Gym/Gymnasium environments, including LunarLander and HalfCheetah variants.

No separate manual dataset download step is documented in the code, except package-managed downloads such as MNIST and simulator assets.
